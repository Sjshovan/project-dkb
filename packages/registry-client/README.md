# @dkb/registry-client

Transport and archive client for the authoritative Laravel DKB Registry.

The package owns Registry URL normalization and health checks, authenticated publication and download calls, Collection endpoints, and safe DKB archive creation/extraction. Host selection and CLI presentation stay outside this package.

See [ADR 0004](../../docs/decisions/0004-monorepo-release-units-and-local-stack.md).
